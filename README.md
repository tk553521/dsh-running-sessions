# 运行会话 / Running sessions

在 DSH 左侧栏底部点击「运行会话」，打开实时活动对话列表。

- 显示所有会话目录中正在运行或等待用户交互的会话，包括目录已列出的子会话。
- 展示标题、运行/等待状态、工作目录、更新时间、会话 ID；子会话另显示父会话 ID。
- 点击整行通过 DSH 的 `uiWorkspace.openSession` 打开对话。
- 支持按标题、目录、ID 筛选；侧栏折叠后保留图标和活动数量。
- 支持 Escape、点击外部关闭、键盘焦点约束及关闭后的焦点恢复。
- 使用 DSH 主题和中文/英文文本；零依赖、无构建步骤。

数据由 DSH 的 `useSessions` 和 `useSessionStatus` selector hooks 提供，事件驱动更新，不轮询，不扫描磁盘，也不为了列表加载每个会话的完整历史。覆盖范围为当前 DSH Host 的会话目录，而非其他独立运行的 DSH Host。

“等待交互”也计入活动数量。更新时间是会话元数据的更新时间，不代表任务启动时间。只做界面浏览和导航，不修改对话、不取消任务、不切换配置。

## 本地安装

通过 DSH 插件管理器安装此目录；已安装后保留目录，当前 profile 会引用它。

## 测试

`node --test test/client.test.cjs`

测试覆盖活动筛选、状态优先级、等待交互、子会话、排序、纯函数输入保护、注册及清理。浏览器显示与点击验证应在已认证的 DSH 页面进行。
